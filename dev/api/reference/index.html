API reference

Models

create_model and list_models apply to every ported model. The other functions are the interface of image backbones and classifiers, which are all the ported models so far.

Metalhead.create_model — Function
create_model(name; pretrained = false, revision = nothing, eltype = Float32, kwargs...)

Build a ported model.

name is a Hub repository ("timm/resnet50.a1_in1k", "HuggingFaceTB/SmolLM2-135M"), a bare architecture ("resnet50", "LlamaForCausalLM"; see list_models), or a local directory containing a config.json and model.safetensors.

By default the weights are random and nothing is downloaded, except the config.json of a repository or directory. With pretrained = true they are loaded from the repository (for a bare architecture, from its default validated checkpoint). revision selects a branch, tag or commit of the repository; validated checkpoints default to the commit they were validated at. The remaining keyword arguments are the original library's model arguments, e.g. timm's num_classes, or the fields of a transformers model's config.json, e.g. num_hidden_layers. Changing num_classes of a pretrained model re-initialises its classifier.

The model is returned in test mode; call Flux.trainmode! before training.

source
Metalhead.list_models — Function
list_models(; pretrained = false, byfamily = false)

Names of the ported architectures, or with pretrained = true the Hub repositories of the checkpoints they were validated against.

By default, returns a Vector{String}, ordered by architecture name. With byfamily = true, returns a Dict{String, Vector{String}} mapping family identifiers to lists in the same order. For timm, the identifiers are its model module names, such as "resnet", "vision_transformer" and "xception_aligned". With pretrained = true, families without validated checkpoints are omitted.

families = list_models(; byfamily = true)
families["xception_aligned"]
list_models(; byfamily = true, pretrained = true)["resnet"]

Metalhead.forward_features — Function
forward_features(model, x)

Run model up to its last feature map, before pooling and classification (timm's forward_features).

This and forward_head, forward_intermediates and feature_info are the interface of image backbones and classifiers, not of every ported model.

source
Metalhead.forward_head — Function
forward_head(model, features; pre_logits = false)

Apply the pooling and classifier of model to the output of forward_features. With pre_logits = true, return the pooled features before the classifier.

source
Metalhead.forward_intermediates — Function
forward_intermediates(model, x; indices = nothing, norm = false, stop_early = false,
                      output_fmt = "NCHW", intermediates_only = false)

Run model and collect the outputs of its stages or blocks, for dense prediction heads (timm's forward_intermediates). The intermediates are those of feature_info.

  • indices: nothing takes all intermediates, an integer k the last k, and a collection the given positions (1-based, unlike timm's).
  • norm: apply the final norm of the model to the intermediates, where timm does.
  • stop_early: skip the stages after the last selected one.
  • output_fmt: "NCHW" returns WHCN feature maps (the Julia layout of PyTorch's NCHW); transformers also accept "NLC", for (C, L, N) tokens.

Returns (features, intermediates), where features is the output of forward_features (truncated with stop_early), or only intermediates with intermediates_only = true. Vision transformers take return_prefix_tokens = true, which returns each intermediate as a (spatial, prefix) tuple, where prefix holds the class and register tokens.

source
Metalhead.feature_info — Function
feature_info(model) -> Vector{NamedTuple}

The intermediates of forward_intermediates, as timm's model.feature_info: for each, its number of channels num_chs, its reduction (stride) relative to the input, and the PyTorch name module_name of the module that outputs it (timm's module).

Metalhead.Timm.pretrained_cfg — Function
Metalhead.Timm.pretrained_cfg(name; revision = nothing) -> NamedTuple

Preprocessing settings of a timm checkpoint (mean, std, input_size, crop_pct, interpolation, ...), as stored in its config.json. name is a Hub repository, a bare architecture (for its default checkpoint) or a local directory, as for Metalhead.create_model. input_size is in PyTorch order (C, H, W).

Builders

create_model calls these with the architecture's default arguments, merged with the checkpoint's configuration and your keyword arguments. The timm builders take timm's keyword arguments, and the transformers builders the fields of the model's config.json.

Metalhead.Timm.convmixer — Method
convmixer(; dim, depth, kernel_size = 9, patch_size = 7, num_classes = 1000, kwargs...)

Port of timm's ConvMixer. Keyword arguments are those of the timm class, with act_layer given by name ("gelu" or "relu"); kernel_size and patch_size are integers or (height, width) tuples.

Metalhead.Timm.create_conv2d — Method
create_conv2d(in_chs, out_chs, kernel_size; stride, dilation, padding = "", groups, depthwise, bias = false, num_experts = 0)

timm.layers.createconv2d. Sizes are Ints or torch-order (h, w) pairs; a vector of kernel sizes gives a MixedConv2d and `numexperts > 0a [CondConv2d](@ref).paddingis""(PyTorch-style symmetric),"same"(TF-style, aConv2dSameunless it is static),"valid"`, or an explicit torch padding.

decode_arch_def(arch_def, depth_multiplier = 1.0; depth_trunc = "ceil",

Decode the block definition strings of the stages of arch_def (a vector of vectors of strings) into a vector of vectors of block arguments. depth_multiplier is a number or one per stage; experts_multiplier scales the number of CondConv experts.

densenet(; growth_rate = 32, block_config = (6, 12, 24, 16), kwargs...)

Metalhead.Timm.efficientnet — Method

Metalhead.Timm.mlp_mixer — Method
mlp_mixer(; img_size = 224, patch_size = 16, num_blocks = 8, embed_dim = 512, kwargs...)

Port of timm's MlpMixer: MLP-Mixer, ResMLP, gMLP and the GLU mixer. Keyword arguments are those of the timm class, with the classes it takes given by name: block_layer is "MixerBlock", "ResBlock" or "SpatialGatingBlock", mlp_layer is "Mlp", "GluMlp" or "GatedMlp" (only the pairs of timm's entry points), norm_layer is "layernorm" (eps = 1e-6) or "affine" and act_layer is "gelu" or "silu". init_values is the layer scale of ResBlock (functools.partial(ResBlock, init_values = ...) in timm). global_pool is "avg" or "", which applies the head to every token.

Metalhead.Timm.mobilenetv3 — Method
mobilenetv3(; block_args, num_classes = 1000, num_features = 1280, kwargs...)

Port of timm's MobileNetV3 class (MobileNet-V3, LCNet, MobileNet-V4): the EfficientNet stem and blocks with the "efficient head", where global pooling comes before the head convolution and there is no norm layer before the classifier (but one after the head convolution with head_norm). num_features is the width of the head convolution. block_args comes from decode_arch_def, norm_layer is nothing or the arguments of BatchNorm2d, and se_layer(channels; act_layer, rd_ratio) creates the squeeze-and-excitation modules. Other keyword arguments are those of the timm class.

source
Metalhead.Timm.resnet — Method
resnet(; block, layers, num_classes = 1000, in_chans = 3, kwargs...)

Port of timm's ResNet (ResNet, ResNeXt, Wide ResNet, SE-ResNet, ECA-ResNet, Res2Net and the c/d/s/t stem variants). Keyword arguments are those of the timm class. block_args is a NamedTuple of keywords for the blocks: attn_layer = "se" or "eca" for BasicBlock and Bottleneck, scale for Bottle2neck.

source
Metalhead.Timm.vgg — Method
vgg(; cfg, num_classes = 1000, in_chans = 3, norm_layer = nothing, kwargs...)

Port of timm's VGG. cfg lists the output channels of the 3x3 convolutions, with "M" for a max pool, and norm_layer = "batchnorm2d" adds batch normalisation (the _bn variants). Other keyword arguments are those of the timm class.

source
Metalhead.Timm.vit — Method
vit(; img_size = 224, patch_size = 16, embed_dim = 768, depth = 12, num_heads = 12, kwargs...)

Port of timm's VisionTransformer, including the options of DINOv2 (init_values, reg_tokens, no_embed_class), CLIP (pre_norm, act_layer = "quick_gelu") and SigLIP (class_token = false, global_pool = "map"), and dynamic_img_size. Keyword arguments are those of the timm class, except that the epsilon of norm_layer is given as norm_eps (timm's partial(LayerNorm, eps = ...)). act_layer is "gelu" (the default), "gelu_tanh" or "quick_gelu". img_size and patch_size are integers or (height, width) tuples, as in timm. Other options (qk_norm, custom layers, ...) error.

source
Metalhead.Timm.xception_aligned — Method
xception_aligned(; block_cfg, num_classes = 1000, in_chans = 3, kwargs...)

Port of timm's XceptionAligned (Aligned Xception, with the pre-activation variant). Keyword arguments are those of the timm class, except that norm_eps stands for the eps of a norm_layer = partial(nn.BatchNorm2d, eps = ...). block_cfg is a sequence of named tuples (in_chs, out_chs, stride) with the optional no_skip and start_with_relu.

source
Metalhead.Transformers.llama_for_causal_lm — Method
llama_for_causal_lm(; vocab_size = 32000, hidden_size = 4096, num_hidden_layers = 32, kwargs...)

Port of transformers' LlamaForCausalLM, built from the fields of its LlamaConfig (the config.json of a checkpoint), with the same names and defaults. create_model ignores the other keys of config.json, such as the token ids and generation settings, as transformers does. Rotary embeddings other than the default (rope_scaling or a rope_parameters with another rope_type, as in Llama 3) error.

The model maps token indices of size (seq_len, batch_size), or a vector for a single sequence, to logits of size (vocab_size, seq_len, batch_size), with causal attention and no padding. Token indices start at 1: add 1 to the ids of a Hugging Face tokenizer. forward_features returns the hidden states after the final norm.

source
Metalhead.Transformers.qwen2_for_causal_lm — Method
qwen2_for_causal_lm(; vocab_size = 151936, hidden_size = 4096, num_hidden_layers = 32, kwargs...)

Port of transformers' Qwen2ForCausalLM, built from the fields of its Qwen2Config with the same names and defaults, and head_dim, which Qwen2Config lacks but transformers reads. transformers derives Qwen2 from Llama's classes, adding a bias to the query, key and value projections, so the model is a LlamaForCausalLM (see llama_for_causal_lm for its inputs and outputs). Sliding-window attention (use_sliding_window, layer_types) and rotary embeddings other than the default error.

source
Metalhead.Transformers.qwen3_for_causal_lm — Method
qwen3_for_causal_lm(; vocab_size = 151936, hidden_size = 4096, num_hidden_layers = 32, kwargs...)

Port of transformers' Qwen3ForCausalLM, built from the fields of its Qwen3Config with the same names and defaults. transformers derives Qwen3 from Llama's classes, with a Qwen3Attention that normalises each query and key head, so the model is a LlamaForCausalLM (see llama_for_causal_lm for its inputs and outputs). Sliding-window attention (use_sliding_window, layer_types) and rotary embeddings other than the default error.

Porting internals

These are used by the ported models and the porting tools. Using the models doesn't need them.

Metalhead.Timm — Module
Metalhead.Timm

Flux ports of timm models. Each ported model mirrors the PyTorch module tree, so that pretrained state_dicts load by name; build them with Metalhead.create_model.

Metalhead.Timm.EfficientNetBuilder — Type
EfficientNetBuilder(; output_stride = 32, pad_type = "", round_chs_fn = round_channels,
                    se_from_exp = false, act_layer = nothing, norm_layer = BATCHNORM2D,
                    aa_layer = nothing, se_layer = nothing, drop_path_rate = 0.0,
                    layer_scale_init_value = nothing)

Builds the stages of blocks from decoded block arguments. Calling it as builder(in_chs, block_args) returns a vector of Chains, and leaves the channel count of the last block in builder.in_chs. se_layer(channels; act_layer, rd_ratio) creates the squeeze-and-excitation module of a block. aa_layer (anti-aliasing, see create_aa) is supported by the cn, er, uir and mqa blocks, and layer_scale_init_value applies to the uir and mqa blocks of MobileNetV4.

source
Metalhead.Timm.MixedConv2d — Type
MixedConv2d(in_chs, out_chs, kernel_sizes; stride, dilation, padding, depthwise, bias)

timm.layers.MixedConv2d (MixConv): the channels are split into one group per kernel size, each convolved with its own kernel size, and concatenated. A ModuleDict in timm, so the convs' keys are 0.weight, 1.weight, ... with no segment for the container.

source
Metalhead.Timm.CondConv2d — Type
CondConv2d(in_chs, out_chs, kernel_size; num_experts, stride, dilation, padding, groups, bias)

timm.layers.CondConv2d: a conv whose kernel (and bias) is a per-sample mixture of num_experts kernels, called as m(x, routing_weights) with routing weights of size (num_experts, batch). weight is torch's (num_experts, params) reversed: column e is the flattened kernel of expert e. The samples are convolved at once, as one grouped conv.

source
Metalhead.Transformers — Module
Metalhead.Transformers

Flux ports of Hugging Face Transformers models. Each ported model mirrors the PyTorch module tree, so that pretrained state_dicts load by name; build them with Metalhead.create_model from a Hub repository.

Language models take token indices starting at 1, as Flux's Embedding does: add 1 to the ids of a Hugging Face tokenizer, and subtract 1 from the index of a logit to get its token id.

source
Metalhead.ArchSpec — Type
ArchSpec(format, name, build; family = "other", defaults = (;),
         references = Pair{String,String}[], ignore = Regex[])

A ported architecture, as config.json files in format name it. build(; kwargs...) constructs the model from the keyword arguments of the original library (e.g. timm's), merged over defaults. references lists repo => sha checkpoints the port was validated against; the first one is the default pretrained checkpoint. ignore lists extra checkpoint keys the model doesn't use. family is the original library's family identifier, used to group architectures in list_models and the documentation.

source
Metalhead.ConfigFormat — Type
ConfigFormat

How the config.json of a model repository names an architecture and its arguments: timm's (architecture, model_args, pretrained_cfg), a future library's architectures, ... A ported library defines a subtype and registers its architectures with it. Only architecture_of is required; the other methods have defaults.

Metalhead.skip_prefix — Function
skip_prefix(format, config, args) -> Union{Nothing, String}

The prefix of the checkpoint keys that don't load into a model built with args, which keeps its initial values (e.g. the classifier after changing num_classes). Throws if the checkpoint can't be loaded into such a model at all.

Metalhead.Checkpoint — Type
Checkpoint(paths)

Lazy view over one or more safetensors files (e.g. the shards of a sharded checkpoint). Indexing with a PyTorch state_dict key returns the tensor in Julia layout, i.e. with the PyTorch dimensions reversed (NCHW → WHCN).

source
Metalhead.load_state! — Function
load_state!(model, ckpt::Checkpoint; prefix = "", ignore = DEFAULT_IGNORE, skip = nothing, strict = true)

Copy the tensors of ckpt into model, matching PyTorch state_dict keys derived from the model structure (see torch_params). Keys matching a regex in ignore may be absent from the model; parameters whose key starts with skip keep their current values. With strict = true, missing keys, unused checkpoint keys and shape mismatches throw.

source
Metalhead.torch_params — Function
torch_params(model; prefix = "") -> (params::Vector{TorchParam}, aliases::Vector{Pair{String,String}})

Enumerate the parameters and buffers of model with their PyTorch state_dict keys. An array reached twice (tied weights) is listed once; later keys are returned as aliases.

source
Metalhead.TorchParam — Type
TorchParam(key, array, kind)

A parameter or buffer of a Flux model, with its PyTorch state_dict key. kind selects the transform from the checkpoint's Julia-layout tensor: :plain (none), :dense (transpose) or :conv (flip the spatial dimensions).
