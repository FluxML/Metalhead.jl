Models

Metalhead has 122 ported timm architectures. Build one with create_model("<architecture>"), or load any Hub checkpoint of it with create_model("timm/<architecture>.<tag>"; pretrained = true).

The 26 checkpoints listed here were compared with PyTorch's outputs (see How models are validated). Bare architecture names load the first one with pretrained = true. Other checkpoints of the same architectures, such as those in the timm organisation, load with the same strict checks.
