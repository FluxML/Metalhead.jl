Models

Metalhead has 298 ported architectures in 14 families. Build one with create_model("<architecture>"), or load a Hub checkpoint of it with create_model("<organisation>/<repository>"; pretrained = true).

Models are grouped by library and family, following the original library's model modules. Wide ResNet, ResNeXt and SE-ResNet belong to the ResNet family; Res2Net and aligned Xception have their own families.

Browse the same families from Julia with list_models:

families = list_models(; byfamily = true)
families["resnet"]
list_models(; byfamily = true, pretrained = true)["resnet"]

The 56 checkpoints listed here were compared with PyTorch's outputs (see How models are validated). Bare architecture names load the first one with pretrained = true. Other checkpoints of the same architectures load with the same strict checks. A dash means no checkpoint has been validated for that architecture.
