Language models

Metalhead also ports language models from Hugging Face Transformers, starting with the Llama architecture (LlamaForCausalLM). They load from the Hub like the timm models:

using Metalhead

model = create_model("HuggingFaceTB/SmolLM2-135M"; pretrained = true)

Any Hub repository whose config.json names a ported architecture loads, with the same strict checks. See the list of models for the architectures and the checkpoints they were validated against.

Generating text

Metalhead has no tokenizers. HuggingFaceTokenizers.jl loads the tokenizer of a Hub repository:

using HuggingFaceTokenizers

tokenizer = from_pretrained(Tokenizer, "HuggingFaceTB/SmolLM2-135M")

prompt = "The capital of France is Paris, and the capital of Italy is"
ids = encode(tokenizer, prompt).ids .+ 1          # Metalhead token indices start at 1
for _ in 1:8                                      # greedy decoding
    push!(ids, argmax(model(ids)[:, end]))
end
println(decode(tokenizer, ids .- 1))

Token indices start at 1, as for Flux's Embedding: add 1 to the ids of a Hugging Face tokenizer, and subtract 1 from the index of a logit to get its token id.

There is no key-value cache yet, so each step of this loop runs the model on the whole sequence.

Inputs and outputs

  • model(ids) takes token indices of size (seq_len, batch_size), or a vector for a single sequence, and returns logits of size (vocab_size, seq_len, batch_size) (or (vocab_size, seq_len)).
  • Attention is causal and there is no padding mask, so the sequences of a batch must have the same length.
  • forward_features returns the hidden states after the final norm, of size (hidden_size, seq_len, batch_size), and forward_head applies the output projection lm_head to them.
  • The weights are converted to eltype (Float32 by default) when they are loaded, whatever their type on the Hub (often bfloat16).

Configuration

The keyword arguments of create_model are the fields of the model's config.json, with the names and defaults of transformers. With a repository, they override its configuration:

create_model("HuggingFaceTB/SmolLM2-135M"; num_hidden_layers = 4)   # random weights
create_model("LlamaForCausalLM"; vocab_size = 1000, hidden_size = 64, intermediate_size = 128,
    num_hidden_layers = 2, num_attention_heads = 4, num_key_value_heads = 2)

Options that the port doesn't implement raise an error. For Llama, these are the rotary embeddings other than the default one, such as the rope_type = "llama3" of Llama 3.1 and later.
