Migrating from Metalhead 0.9

Metalhead 0.10 replaces the hand-written models with ports of timm models, built with create_model. The old API still works in 0.10, with deprecation warnings, and will be removed in 0.11. The deprecated API covers:

  • the model constructors (ResNet(50), ViT(:base), ...) and their lowercase builders (Metalhead.resnet, ...);
  • the Metalhead.Layers module;
  • pretrain = true, and the weights it loads from the FluxML organisation on the Hub.

What changes

0.90.10
ResNet(50)create_model("resnet50")
ResNet(50; pretrain = true)create_model("timm/resnet50.tv2_in1k"; pretrained = true)
nclasses = 10num_classes = 10
inchannels = 1in_chans = 1
imsize = (256, 256)img_size = (256, 256) (for ViT and the MLP mixers)
backbone(model)(x)forward_features(model, x)
classifier(model)(features)forward_head(model, features)
layers from Metalhead.LayersFlux layers

The input layout (width × height × channels × batch) is unchanged. Models are now returned in test mode.

The keyword arguments are timm's, so they differ per family. The docstrings of the old constructors don't apply to the new models: look up the timm model instead. The models also have a different structure (the PyTorch one), so code that indexes into a model, like model.layers[1][2], needs updating.

Pretrained weights

The pretrained weights of 0.9 came from torchvision. timm hosts the same weights, as <model>.tv_in1k (torchvision's IMAGENET1K_V1) and <model>.tv2_in1k (IMAGENET1K_V2). The table gives the repository with the version that pretrain = true loaded. For ResNet-50, the outputs of the two models are bitwise identical.

0.90.10
ResNet(18; pretrain = true), ResNet(34; ...)create_model("timm/resnet18.tv_in1k"; pretrained = true), "timm/resnet34.tv_in1k"
ResNet(50; pretrain = true), 101, 152"timm/resnet50.tv2_in1k", "timm/resnet101.tv2_in1k", "timm/resnet152.tv2_in1k"
WideResNet(50; pretrain = true), 101"timm/wide_resnet50_2.tv2_in1k", "timm/wide_resnet101_2.tv2_in1k"
ResNeXt(50; pretrain = true) (32×4d)"timm/resnext50_32x4d.tv2_in1k"
ResNeXt(101; cardinality = 32, base_width = 8, pretrain = true)"timm/resnext101_32x8d.tv2_in1k"
ResNeXt(101; cardinality = 64, base_width = 4, pretrain = true)"timm/resnext101_64x4d.tv_in1k"
VGG(11; pretrain = true), 13, 16, 19"timm/vgg11.tv_in1k", "timm/vgg13.tv_in1k", "timm/vgg16.tv_in1k", "timm/vgg19.tv_in1k"
ViT(...; pretrain = true)no torchvision weights on the Hub; use timm's, e.g. "timm/vit_base_patch16_224.augreg2_in21k_ft_in1k"
SqueezeNet(; pretrain = true)no replacement

timm also has newer checkpoints of most of these architectures, usually more accurate. See the model list.
